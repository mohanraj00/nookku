# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Read the full text there. This page says in my own words what it asks.

- Treat each person with respect, in issues, pull requests, reviews and each other project space.
- Criticize the work, not the person. Accept a correction, and correct your own mistakes.
- Do not harass, insult or threaten a person. Do not use sexual language or images.
- Do not publish the private information of a person without their permission.
- These rules also apply when you speak for the project in a public space.

To report a problem, use a private security advisory on GitHub: the Security tab of this repo, as [SECURITY.md](SECURITY.md) says. Do not open a public issue for it. I read each report, keep the name of the reporter private, and take action as the Covenant describes, from a warning to a ban.
