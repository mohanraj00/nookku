---
name: setup
description: Connect a Nookku test to the app in this project. Use it when the tester asks to configure Nookku, to write the entry, or to make a test run the app.
---

Run `nookku setup`. It prints the setup guide. Do each step of the guide.

If the command is not found, tell the tester to install it with `uv tool install nookku`.
